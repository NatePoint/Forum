# ЗнаниеОбмен — MVP форума обмена знаниями (Anti-Reddit)

Статический форум без бэкенда: чистый HTML + Vanilla JS + Firebase Firestore (SDK через CDN).
Данные общие для всех посетителей. Нет лайков, рейтингов и бесконечного скролла — только пагинация по 10 тем.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Главная: список тем, модалка создания темы, правила |
| `topic.html` | Страница темы: текст, ответы в реальном времени, кнопка «Лучший ответ» |
| `style.css` | Трехколоночный макет, плоский минимализм, серая гамма |
| `app.js` | Инициализация Firebase + логика главной страницы |
| `topic.js` | Инициализация Firebase + логика страницы темы |

## Инструкция по Firebase — 3 шага

**Шаг 1. Создайте проект.**
Зайдите на https://console.firebase.google.com → «Добавить проект» → назовите его (например, `knowledge-forum`) → Google Analytics можно отключить → «Создать проект».

**Шаг 2. Создайте веб-приложение и возьмите конфиг.**
В проекте нажмите иконку `</>` («Добавьте приложение для Веба»), зарегистрируйте приложение
(домен указывать не обязательно) и скопируйте объект `firebaseConfig` с экрана — там есть
`apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`.
Вставьте этот конфиг в начало **обоих** файлов: `app.js` и `topic.js` (место помечено комментарием
`// ВСТАВЬ СЮДА СВОЙ КОНФИГ FIREBASE`).

**Шаг 3. Включите Firestore и задайте правила.**
В консоли: «Build» → «Firestore Database» → «Create database» → регион любой → режим «Test mode»
(для MVP; для продакшена замените правила на более строгие). Коллекции `topics` (темы) и
`answers` (ответы) создадутся автоматически при первой записи. Пример правил тестового режима:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

После этого откройте `index.html` локально (или залейте файлы на любой бесплатный статический
хостинг) — форум готов к работе.

## Структура данных Firestore

- `topics/{id}`: `title`, `text`, `author`, `tags[]`, `createdAt`, `answersCount`, `bestAnswerId`
- `answers/{id}`: `topicId`, `text`, `author`, `createdAt`

Отметить или снять «Лучший ответ» может только тот, кто введёт имя автора темы (упрощённая
проверка без авторизации — допущение уровня MVP).
